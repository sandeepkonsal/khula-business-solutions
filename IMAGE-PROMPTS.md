# AI images for the service pages

Each service page shows an illustration by default. To use a real AI image instead:

1. Generate it with Midjourney, ChatGPT/DALL·E, Adobe Firefly or Canva at **1600 × 1200 px (4:3)**.
2. Save it as `public/images/services/<slug>.jpg` (exact file names below).
3. Run `npm run build`. A page automatically uses its image when the file exists, so you can swap them one at a time.

Style to keep every image consistent: *Premium editorial photography, warm natural light, subtle copper/orange accents, dark charcoal tones, shallow depth of field, South African corporate setting, diverse professionals, no text, no logos, no watermarks.*
